# Worldfall

The website for Worldfall, a first-person mod for WorldBox (beta): https://s3cond2.github.io/worldfall/

Download: [Worldfall.zip](https://github.com/s3cond2/worldfall/releases/latest) (install steps and checksums are on the site).

This repository holds only the website. Every picture is captured in the game with the mod running.
Worldfall is an unofficial fan mod; WorldBox is made by Maxim Karpenko.
